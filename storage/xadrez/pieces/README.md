# Peças de xadrez

Sprites usados pelo `/xadrez` (`services/games/chessBoard.js`).

- **Autor:** Cburnett
- **Origem:** Wikimedia Commons — [Standard chess pieces](https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces)
  (arquivos `Chess_klt45.svg`, `Chess_pdt45.svg`, etc.), rasterizados em 250px.
- **Licença:** CC BY-SA 3.0 / GFDL / BSD — o uso exige crédito ao autor.

Nomenclatura: `<cor><peça>.png`, com cor `w` (brancas) ou `b` (pretas) e peça
`K Q R B N P` (rei, dama, torre, bispo, cavalo, peão) — as mesmas letras que o
`chess.js` devolve em `board()`/FEN.
